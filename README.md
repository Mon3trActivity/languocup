# languocup
烂果杯专用

## 音乐与手机端

每次进入默认开启音乐，以正常音量从 Intro 第2秒开始播放（跳过前两秒），结束后循环 Loop。浏览器若限制有声自动播放，点击开场、任意格子，或右上角“点击播放”即可开始。右上角可关闭音乐与音效，再次开启会接着播放，不会重头开始。

背景音乐为《沉沦者梦呓》的游戏内 Intro 与 Loop，文件为 `assets/blackflow/audio/drowning-dream-intro.mp3` 和 `assets/blackflow/audio/drowning-dream-loop.mp3`。来源：[PRTS社区音乐鉴赏](https://m.prts.wiki/w/沉沦者的黑流树海)，原始音频由鹰角网络持有版权。仅用于个人非商用项目；非商用不等于获得再分发授权，公开发布或提交PR前请确认资源许可。

手机端使用独立的紧凑布局，保持5×5正方形棋盘。点击格子标记或取消，并在棋盘下方显示完整条件。
